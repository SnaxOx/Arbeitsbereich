# Handy-Ersatzteile Lager (Frontend-Demo)

Eine leichte, statische Web-App zur Verwaltung von Smartphone-Ersatzteilen mit moderner Optik.

## Nutzung
1. Öffne die Datei `index.html` direkt im Browser (Doppelklick) **oder** starte einen kleinen lokalen Webserver, z. B.:
   ```bash
   python3 -m http.server 8000
   ```
   und rufe anschließend [http://localhost:8000](http://localhost:8000) auf.
2. Filtere oder suche nach Teilen, passe Bestände mit den Schnellaktionen an und exportiere die Ansicht als CSV.
3. Über das Formular kannst du neue Teile hinzufügen.

> Hinweis: Es gibt keinen Build-Schritt oder Backend-Server – die Seite funktioniert direkt aus den statischen Dateien.
