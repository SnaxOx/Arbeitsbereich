# Handy-Ersatzteile Lager (Frontend-Demo)

Eine leichte, statische Web-App zur Verwaltung von Smartphone-Ersatzteilen mit moderner Optik.

## Nutzung
1. Öffne `index.html` im Browser.
2. Filtere oder suche nach Teilen, passe Bestände mit den Schnellaktionen an und exportiere die Ansicht als CSV.
3. Über das Formular kannst du neue Teile hinzufügen.

Keine Build- oder Backend-Abhängigkeiten erforderlich.
